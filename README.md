# 🌍 terreX

**terreX** is a modern, single-page web application that combines a powerful
**currency converter**, **calculator**, 
and **forex toolkit** into one seamless experience. It is designed for everyday users, 
travelers, businesses, and forex traders who need quick access to currency conversions, 
exchange rates, and market insights.

## ✨ Features

* 💱 Live Currency Converter
* 🧮 Built-in Smart Calculator
* 📊 Live Exchange Rates
* 📈 Historical Exchange Rate Charts
* 📰 Today's Financial & Forex News
* 👤 User Authentication (Sign In & Sign Up)
* ⭐ Favourite Currency Pairs
* 🕒 Conversion History
* 🌙 Dark Mode
* 📱 Fully Responsive Design

## 📈 Forex Tools

CurrenX also includes tools tailored for forex traders:

* Pip Value Calculator
* Position Size Calculator
* Profit & Loss Calculator
* Margin Calculator
* Risk/Reward Calculator
* Currency Strength Meter
* Economic Calendar
* Trading Session Status
* Forex Pair Watchlist
* Quick Access to Major Currency Pairs

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Exchange Rate API
* Financial News API
* Charting Library (for historical exchange rates)

## 🎯 Project Goal

The goal of CurrenX is to provide an all-in-one financial utility that goes beyond simple currency conversion. It combines essential tools with market information to help users make informed decisions while keeping the interface clean, fast, and easy to use.
